# 📖 คู่มือใช้งาน LLM Wiki — ฉบับเข้าใจง่าย

> สำหรับทุกคนในทีม ไม่ต้องมีพื้นฐานพิเศษ อ่าน 5 นาทีแล้วใช้เป็น.

## นี่คืออะไร?

`wiki/` คือ **"สมองส่วนกลางของโปรเจกต์"** — เป็นไฟล์โน้ตที่อธิบายว่าระบบทำงานยังไง,
ทำไมถึงออกแบบแบบนี้, และมีกับดักอะไรบ้าง. **AI (Claude) เป็นคนเขียนและดูแลให้** เราแค่
สั่งงานและคอยชี้ทิศ.

ประโยชน์: ไม่ต้องไล่อ่านโค้ดเป็นพัน ๆ บรรทัดทุกครั้ง, คนใหม่ onboard เร็ว, ความรู้ไม่หายไป
กับคนที่ลาออก.

## 🔑 จำแค่ 3 คำสั่ง

| คำสั่ง | ใช้เมื่อ | ตัวอย่าง |
|--------|---------|----------|
| **query wiki** | ก่อนเริ่มงานที่ยังไม่คุ้น | `query wiki: ระบบ auth ทำงานยังไง` |
| **ingest** | เพิ่งทำอะไรเสร็จและอยากให้จำ | `ingest งานนี้: ...` |
| **lint วิกิ** | อยากเช็คว่าวิกิยังถูกต้อง | `lint วิกิ` |

> คำสั่งพวกนี้ไม่ใช่ปุ่มวิเศษ — มันคือ "คำที่เรานัดกันไว้" และ AI รู้จักเพราะมีไฟล์
> `CLAUDE.md` + `wiki/WIKI.md` สอนมันไว้ พิมพ์เป็นภาษาคนปกติได้เลย ไม่ต้องเป๊ะ.

## 🔄 วงจรการทำงานประจำวัน

```
┌──── เริ่มงาน ────┐   ┌─── เขียนโค้ด ───┐   ┌──── จบงาน ────┐
│  query wiki ...   │ → │  คุยกับ AI ปกติ  │ → │  ingest ...    │
│ (ถามก่อนลงมือ)    │   │ (วิกิไม่มายุ่ง)   │   │ (ถ้าควรจำ)     │
└──────────────────┘   └─────────────────┘   └────────────────┘
```

**กฎทอง 3 ข้อ**
1. **Query ก่อนเริ่มเสมอ** — คุ้มที่สุด เพราะโหลดความเข้าใจระบบเข้าหัวก่อนลงมือ.
2. **ไม่ต้อง ingest ทุกอย่าง** — เฉพาะของที่ "ครั้งหน้าอยากรู้แต่จะลืม".
3. **เริ่ม session ใหม่ไม่ต้องเล่าอะไร** — AI อ่าน `CLAUDE.md` → `wiki/` เองอัตโนมัติ.

## ✅ ควร ingest / ❌ ไม่ต้อง ingest

| สถานการณ์ | ingest? |
|-----------|---------|
| เพิ่ม feature / module ใหม่ | ✅ |
| ตัดสินใจเชิงสถาปัตยกรรม (เลือก A ไม่เลือก B) | ✅ (เป็น ADR) |
| เจอบั๊ก/กับดักที่เสียเวลานานกว่าจะแก้ | ✅ (ลง gotchas) |
| ตั้งแพตเทิร์น/แนวทางใหม่ที่อยากให้คนอื่นทำตาม | ✅ |
| แก้ typo, ปรับสี/ระยะห่างเล็กน้อย, rename ตัวแปร | ❌ |
| ลองอะไรแล้วลบทิ้ง | ❌ |

## 🧰 คลังตัวอย่าง prompt (ก๊อปไปใช้ได้เลย)

### 🔍 Query — ถามก่อนเริ่ม
```
query wiki: ระบบแจ้งเตือน (notification) ทำงานยังไงตั้งแต่ MQTT ถึงการส่ง LINE
```
```
query wiki: ถ้าจะเพิ่ม channel แจ้งเตือนใหม่ (เช่น Email) ต้องแก้ตรงไหนบ้าง reuse อะไรได้
```
```
query wiki แล้วดูโค้ดจริงด้วย: หน้า Realtime ดึงข้อมูลมาจากไหน ทำไมไม่ใช่ MQTT สด
```
```
query wiki: ระบบ permission ตัดสินใจยังไงว่า user คนนี้เข้าเมนูไหนได้
```

### 🏗️ เริ่ม feature ใหม่ (query นำ แล้วค่อย code)
```
query wiki ก่อนแล้วค่อยลงมือ:
ฉันจะเพิ่มหน้า export รายงานเป็น Excel
1) ดูว่าระบบ report กับ permission ทำงานยังไง
2) มี library/แนวทางอะไรในโปรเจกต์ที่ใช้ได้
3) เสนอแนวทาง 2-3 แบบให้เลือกก่อนเขียนโค้ด
```

### 🐛 Debug / สืบสวน
```
query wiki: บั๊กนี้น่าจะเกี่ยวกับ permission — มี gotcha อะไรเรื่องการเทียบ id ไหม
```
```
ช่วยหาว่าทำไม web push ไม่ส่ง โดยเช็ค gotchas ในวิกิก่อนว่ามีเคสนี้ไหม
```

### 📝 Ingest — บันทึกกลับเข้าวิกิ (ใส่ครบ: อะไร + ลงไหน + เน้นอะไร)
```
ingest งานนี้: สร้างหน้า frontend styling conventions ในวิกิ
เน้นแพตเทิร์นปุ่มเลือกแบบ pill + active state สีฟ้า ที่เราเพิ่งตกลงกัน
```
```
ingest: เพิ่งเพิ่ม email notification channel — อัปเดตหน้า realtime-and-notifications
และถ้ามี decision เรื่องเลือก SMTP ให้สร้าง ADR ด้วย
```
```
ingest gotcha: เพิ่งเสียเวลา 2 ชม.เพราะ timezone ของ app กับ DB ไม่ตรง บันทึกลง gotchas
```

### 🧹 Lint — ดูแลสุขภาพวิกิ (ทำเดือนละครั้งก็พอ)
```
lint วิกิ: หาหน้าที่ขัดแย้งกัน, อ้างโค้ดที่ลบไปแล้ว, หรือ concept ที่ยังไม่มีหน้า
```

### 🆕 Onboarding คนใหม่
```
ฉันเพิ่งเข้าทีม ช่วยพาทัวร์โปรเจกต์จากวิกิหน่อย เริ่มจากภาพรวมแล้วเจาะส่วนสำคัญ
```

## 🖥️ Obsidian (ทางเลือก — ไม่บังคับ)

วิกิคือไฟล์ `.md` ธรรมดา จะเปิดด้วยอะไรก็ได้. ถ้าอยากดูสวย ๆ + เห็นแผนที่ความเชื่อมโยง:
1. เปิด Obsidian → **Open folder as vault** → เลือกโฟลเดอร์ `SmartEEweb`.
2. เปิด `wiki/index.md` แล้วลองกด **graph view**.

> Obsidian เป็นแค่ "หน้าต่างอ่าน" — เปิดหรือไม่เปิดก็ไม่กระทบการทำงานของ AI.

## ❓ FAQ สำหรับทีม

**Q: AI จะบันทึกทุกอย่างที่ฉันทำลงวิกิอัตโนมัติไหม?**
A: ไม่ — บันทึกเฉพาะตอนสั่ง `ingest`. นี่คือ by design เพื่อไม่ให้วิกิรก.

**Q: ฉันต้องเปิด Obsidian ตลอดไหม?**
A: ไม่ต้อง. เปิดเฉพาะตอนอยากอ่าน/ดูภาพรวม.

**Q: ความรู้พวกนี้ติดไปกับ git ไหม?**
A: ติด — `wiki/` กับ `CLAUDE.md` อยู่ใน repo. clone ที่ไหนก็มีครบ.
(ยกเว้น "Claude memory" ที่อยู่บนเครื่องแต่ละคน ไม่ติดไปกับ git.)

**Q: ฉันต้องบอก AI ว่าอ่าน folder ไหนไหม?**
A: ไม่ต้อง. มันอ่าน `CLAUDE.md` อัตโนมัติ ซึ่งชี้ไป `wiki/index.md` ให้เอง.

**Q: เริ่ม session ใหม่ต้องเล่าโปรเจกต์ใหม่ทุกครั้งไหม?**
A: ไม่ต้อง. แค่พิมพ์ `query wiki: ...` ได้เลย.
